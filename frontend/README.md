# AI Workspace Frontend

React + Vite frontend integrated with the backend API.

## Setup

```powershell
cd "c:\Users\shekh\Desktop\Complete Major 1\frontend"
Copy-Item .env.example .env
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

The backend must be running at:

```text
http://localhost:5000
```

## Implemented Screens

- Login/Register
- Dashboard
- AI Chat with Socket.IO streaming fallback to HTTP
- Documents upload/list/delete
- Semantic search
- Tasks
- Study planner
- Coding assistant
- Memory
- Agents
- Settings
